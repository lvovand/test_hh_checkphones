# Мини-синхронизатор заявок (PHP)

Забирает сырые заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`,
отбрасывает невалидные, дедуплицирует по телефону и отдаёт JSON.

**Живой URL:** https://landos.prettysites.ru/hh-sync/result

## Правила
- Телефон: из строки берутся только цифры. 11 цифр с `7`/`8` в начале → `+7…`; 10 цифр (номер без кода страны) → `+7…`. Всё остальное — невалидно (`invalid_dropped`).
- Дубль по телефону: остаётся запись с максимальным `amount`; при равных — с более поздним `created_at`; при полном равенстве — с большим `id` (чтобы результат не зависел от порядка).
- Порядок клиентов — по первому появлению телефона в источнике.
- `duplicates_merged` = валидные заявки − уникальные клиенты.

## Идемпотентность
Каждый запрос — полная пересборка из источника чистой функцией `Sync::process()`; снимок `data/result.json`
перезаписывается целиком (атомарно через rename). Повторный запуск даёт тот же результат, дублей не появляется.
Если источник недоступен, отдаётся последний успешный снимок (заголовок `X-Data-Source: snapshot`).

## Структура
- `src/Sync.php` — нормализация, валидация, дедупликация (без I/O).
- `src/config.php` — URL источника и токен из переменных окружения (`ORDERS_URL`, `ORDERS_TOKEN`).
- `public/index.php` — HTTP-эндпоинт: fetch → process → JSON.
- `deploy/` — тонкая точка входа для веб-корня хостинга; код лежит вне docroot.
- `tests/run.php` — тесты: `php tests/run.php`.

## Запуск локально
```
php -S localhost:8000 -t public
curl localhost:8000
```
